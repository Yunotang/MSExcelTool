Adapter 規格

電源 Adapter（變壓器）的規格分成三層：電氣（多少電）、機構（插頭長什麼樣）、法規（能效與安規）。三層任一層不合，機器就不能用或不能賣。

240WUSB-C PD 3.1 EPR 的功率上限（48V × 5A）
48VEPR 新增的最高電壓，原本只到 20V
100mWEU CoC Tier 2 的空載功耗天花板
0.4mm5.5×2.5 與 5.5×2.1 的孔徑差，最常見的誤插來源

第一層：電氣規格

看銘牌就找得到，四項全部要對。

項目常見值不對會怎樣
輸出電壓 V5V / 12V / 19V / 19.5V / 20V太高燒輸入級；太低開不了機或強制降頻
輸出電流 A2A ~ 11.8A與電壓相乘決定瓦數
功率 W45W / 65W / 90W / 120W / 230W不足 → 只有高負載才當機，最難重現的客訴
極性中心針 +、外殼 −（業界慣例）反接 → 插下去就冒煙
輸入範圍100–240V~ 50/60Hz（全球通用）只支援單一電壓的機種帶出國會燒毀

另外還有兩項容易被忽略：連漪電壓（ripple）影響系統穩定度，線徑 AWG 與線長決定壓降——同樣 19V，線太細太長到機器端可能只剩 18V。

第二層：機構規格（接頭型式）

這一層最亂。電壓瓦數對了，插頭插不進去或插進去接觸不良，一樣沒用。

型式尺寸特徵
通用桶狀 Barrel5.5×2.5mm、5.5×2.1mm市面最泛用，也最容易誤插——差 0.4mm 看不出來
Dell / HP 桶狀7.4×5.0mm（舊）、4.5×3.0mm（新）中心多一根 ID 針，用來辨識原廠與瓦數
Lenovo Slim Tip7.5×3.0mm 長方形扁平方形，非圓孔，完全不可能誤插他牌
Lenovo Square10.5×4.2mm舊款 ThinkPad 方形接頭
小型設備4.0×1.7mm、3.5×1.35mm路由器、小家電、Mini PC 常見
USB-C PDType-C 24 pin唯一有雙向協商能力的，正反可插

Dell 與 HP 的中心 ID 針是雙面刃：能擋掉雜牌變壓器，但那條細訊號線一斷，主機就跳「無法辨識變壓器」並強制降頻——機器沒壞，只是變慢，這種客訴最難處理。

第三層：能效與安規

能效等級（決定能不能賣）

標準地區重點
DoE Level VI美國，強制看多個負載點的平均主動效率
EU CoC Tier 2歐盟，自願但業界視為門檻多一個 10% 負載的效率要求；空載上限 100mW
ErP Lot 6歐盟，強制待機與空載功耗規範

CoC Tier 2 在 49W 以下的機種通常比 DoE Level VI 更嚴。說明書必須揭露平均主動效率、10% 負載效率、空載功耗三個數字。

安規認證（決定能不能進關）

  • UL / cUL（美加）、CE（歐盟）、BSMI（台灣）、PSE（日本）、CCC（中國）
  • 外殼阻燃等級 UL 94 V-0——2004 年 IBM 召回的原因正是「過熱熔穿外殼」
  • 醫療用另有 IEC 60601，漏電流要求遠嚴於一般 ITE

接頭型式，選一個看它的坑

同樣是把電送進機器，五種做法的風險完全不同。
